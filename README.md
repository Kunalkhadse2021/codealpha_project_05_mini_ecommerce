# Mini E-Commerce App

## Description
A responsive Mini E-Commerce App developed using HTML, CSS, and JavaScript. Users can browse products, add items to the shopping cart, update quantities, and view the total price.

## Features
- Product listing
- Add products to cart
- Increase or decrease quantity
- Remove products from cart
- Automatic total price calculation
- Checkout preview
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Shopping cart functionality

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Browse products and add them to your cart.

## Note
This is a demonstration project. It does not process real payments.
